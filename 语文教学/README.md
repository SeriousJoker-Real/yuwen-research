# 语文课前调研智能体

> 以学定教 · 让语文课堂更有针对性

一个面向中学/高中语文教师的在线教学辅助工具，通过课前调研摸清学生真实学情，再用AI分析结果反推教学重点。

## ✨ 核心功能

### 1. 教师端 👨‍🏫
- **调研管理**：创建、发布、管理课前调研
- **AI出题**：根据课文和文体自动生成调研题目
- **课文库**：常用课文快速创建调研
- **班级管理**：多班级对比分析
- **调研报告**：五维度学情分析 + 教学目标建议

### 2. 学生端 📝
- 链接访问，无需注册
- 逐题作答，随时修改
- 一键提交

### 3. 分析报告 📊
- **五维度分析**：字词基础、内容理解、阅读感受、思维深度、共性问题
- **分层教学目标**：基础目标 / 提升目标 / 拓展目标
- **班级对比**：多班级横向对比
- **学生详情**：查看单个学生完整回答

### 4. 多文体支持 📖
- 散文：情景交融、语言品味、作者心境
- 小说：人物形象、情节结构、环境描写、主题探究
- 诗歌：意象把握、情感体悟、炼字赏析、意境感受
- 文言文：字词积累、句子翻译、内容理解、文化常识

## 🚀 快速开始

### 方式一：公网部署（推荐，支持扫码访问）

详见 [部署指南](./DEPLOY.md)

**推荐方案：Coze Pages 前端 + Vercel 后端**
- 完全免费，公网可访问
- 支持二维码扫码访问
- 师生无需安装任何软件

### 方式二：本地运行（开发/测试）

```bash
cd server
npm install
cp .env.example .env
# 编辑 .env 填入扣子 API Token 和 Bot ID
npm start
```

然后访问：http://localhost:8080/

### 方式三：纯前端模式

不需要安装依赖，直接打开 `public/index.html` 即可使用，但数据只存在浏览器本地。

## 📱 二维码扫码访问

本项目支持二维码扫码访问：
- **调研专属二维码**：每个调研生成专属二维码，学生扫码直达填写页
- **首页入口二维码**：扫码后进入首页，选择对应调研
- **下载二维码**：可下载 PNG 图片，打印或投影使用

详见 [部署指南](./DEPLOY.md) 了解如何部署到公网实现扫码访问。

## 🔧 配置扣子API

1. 访问 https://www.coze.cn/open/oauth/pats 获取个人访问令牌
2. 在扣子平台创建你的智能体，获取 Bot ID
3. 将 Token 和 Bot ID 填入 `server/.env` 文件

```env
COZE_API_TOKEN=你的API_TOKEN
COZE_BOT_ID=你的BOT_ID
PORT=8080
```

## 📋 使用流程

1. **教师创建调研** → 填写课文信息 → AI生成题目 → 手动调整 → 发布
2. **生成学生链接** → 分享给学生填写
3. **学生填写** → 打开链接 → 填写班级姓名 → 答题 → 提交
4. **查看报告** → AI分析学情 → 五维度报告 → 教学目标建议

## 🎯 五维度分析框架

| 维度 | 说明 |
|------|------|
| **字词基础** | 生字词认读、关键词理解、文言词汇积累 |
| **内容理解** | 课文大意、情节脉络、人物形象、文意把握 |
| **阅读感受** | 情感共鸣、兴趣点、审美体验、个人感悟 |
| **思维深度** | 分析评价、质疑提问、联想拓展、鉴赏能力 |
| **共性问题** | 全班普遍薄弱点、高频疑问、需要重点突破的内容 |
